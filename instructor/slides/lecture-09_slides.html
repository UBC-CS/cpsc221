A new memory model:

template <class T>
struct Node {
    T data;
    Node * next;
    Node(T nD, Node * nN = nullptr) : data(nD), next(nN) { }
};

What is the result of each statement?

int main() {
    Node<int> nn(5);
    Node<int> * pnn;
}

Write code that would result in each of these memory configurations, in order:

Node<int> nn(5); will not compile on its own – the constructor takes a value, so this one is fine, but point out that there is no default constructor. Node<int> * pnn; allocates nothing at all: it is a pointer with garbage in it, exactly like int *p; on Friday.

Then build the two pictures:

  • one node holding 8, next is nullptr
  • two nodes, 6 then 8, the second one’s next is nullptr

The answers are new Node<int>(8) and new Node<int>(6, new Node<int>(8)), and the second one is worth writing out slowly. The constructor’s default argument is what makes it read so neatly.

The diagonal slash means nullptr. Establish that notation now – it is the whole rest of the term.

Example 1: insertAtFront

insertAtFront<farmAnimal>(head, cow);
void insertAtFront(Node * ________ curr, LIT e) {

}

Running time?

The blank in the signature is the point of the slide: it has to be Node *& curr, a reference to the pointer. Pass the pointer by value and you change a copy, and the caller’s head still aims at dog.

This is the first place the course needs a pointer to be passed by reference, and it is exactly the situation the double pointer on PEX2 describes – a function that has to change where the caller’s pointer aims. Node ** would also work; Node *& is the C++ way.

Body is two lines: curr = new Node(e, curr); or the long form. \(\Theta(1)\) – no traversal, which is the whole appeal of a list.

Example 2: printReverse

void printReverse(Node * curr) {

}


Running time?   (our first recurrence)

Recurse first, print after:

if (curr == nullptr) return;
printReverse(curr->next);
cout << curr->data;

The whole lesson is that swapping those two lines prints forwards. The recursion is doing the reversing, not any code they wrote.

Then the recurrence, slowly, because it is the first one. \(T(n) = T(n-1) + \Theta(1)\), with \(T(0) = \Theta(1)\). Unroll it on the board: \(n\) levels, constant work each, so \(\Theta(n)\).

Worth saying out loud that the call stack is holding \(n\) frames at the deepest point – the space is \(\Theta(n)\) too, which an iterative version would not need. First time space and time come apart.

Example 3: printReverseOdds

void printReverseOdds(Node * curr) {
    // no items in list


    // one item in list


    // >1 item in list

}

Running time?

Prints every other node, from the back: for 8 4 2 6 3 1 the odd-indexed values are 4, 6, 1, so it prints 1 6 4.

Three cases, and that is the point of the slide. A recursion that steps by two needs two base cases, not one:

  • curr == nullptr – nothing to do
  • curr->next == nullptr – one node left, and it is at an even index, so nothing to print either
  • otherwise recurse on curr->next->next, then print curr->next->data

Students who write only the first base case walk off the end of the list on lists of even length. Let that happen before fixing it.

Running time: \(T(n) = T(n-2) + \Theta(1)\), so \(n/2\) levels – still \(\Theta(n)\). Good place to note that halving the work per level does not change the growth rate.

Example 4: reverse

Node * reverse(Node * curr) {
    if (curr != nullptr && _________________) {
        Node * revRest = ______________________



    }
    return ______________;
}

Running time?

Blanks: curr->next != nullptr; revRest = reverse(curr->next); then curr->next->next = curr; and curr->next = nullptr;; return revRest, or curr in the base case.

The move that makes it work: after the recursive call, curr->next still points at the node that is now the tail of the reversed rest. So curr already has a handle on where to attach itself. Draw that – it is the only hard idea here.

Then curr->next = nullptr, because curr is about to be the last node. Forget that line and the list has a cycle, and printing it never terminates.

\(T(n) = T(n-1) + \Theta(1) = \Theta(n)\), same shape as printReverse.

This function returns the new head rather than taking Node *&. Worth contrasting with insertAtFront – two different ways to let a function change what the caller’s pointer aims at.
